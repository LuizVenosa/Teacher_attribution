# Previous public-pilot simplification

This records the earlier refactor. The later controlled implementation restores components explicitly required by the new research specification; see [implementation.md](implementation.md).

# Refactor decisions

The active pipeline now has one config and one CLI. This is a breaking change: old checkpoints, prompt splits, generated outputs, and script commands are not compatible. New artifacts use schema version 2 and a separate `runs/` directory.

| Previous component | Decision |
|---|---|
| Separate teacher/student generation scripts | One generation command, with model/split filtering and reproducible resume |
| Four-way public benchmark with LaMini/FLAN labels | Two documented relationships; transfer mechanism explicit; public pilot scope stated |
| Multiple MiniLM/default/ablation configs | One experiment config and explicit training overrides |
| Independent per-split shuffles | Stable source-group assignment, text deduplication, cross-split audit, immutable manifests |
| Prompt-first 512-token truncation | Separate prompt cap and guaranteed response-token budget |
| Three overlapping evaluators | One evaluator with saved predictions, shared support sets, dataset breakdowns, paired intervals |
| Learned set aggregator | Removed; mean per-prompt scores is the common baseline |
| BERTScore/POS fallback, unused embedding paths | Removed; focus on runnable lexical, frozen, classification-only and contrastive controls |
| Hand-maintained figures and root summaries | Historical files retained; new summary generated directly from evaluator metrics |
| Hyperparameter grid launcher | Removed; only explicit objective/input/seed controls |
| Ten specialized cluster jobs | One argument-forwarding SLURM wrapper |
| Tracked egg-info and unused placeholders | Removed; packaging metadata is generated |
| Contaminated tracked example prompt files | Removed; smoke inputs are generated by the tests |
| Historical report/results | Preserved with an explicit historical-status note |

When a checkpoint is supplied, the frozen control uses the checkpoint's input settings, including response-only ablations. Without a checkpoint it uses the main config. Model-specific tokenizers receive the same stored textual prompt, and generation refuses inputs that exceed context rather than changing the content silently.

Supervised probes learn from labeled student outputs. This is not WTYT's teacher-output training protocol. The public preset does not eliminate student-identity confounding. The held-out-student mode validates checkpoint assignments but cannot independently prove lineage metadata or enforce a controlled distillation process.

No new benchmark scores are claimed by this refactor. First prepare and audit a small new run, inspect generation and token-retention statistics, and only then allocate compute for repeated experiments.
